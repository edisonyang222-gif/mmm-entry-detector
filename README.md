# 黃金 MMM 進場偵測器

中文雙模型指標：**趨勢共振** + **盤整均值回歸（多空雙吃）**；面板位置可在設定中自選。

> 歷史回測 ≠ 未來獲利。這是技術工具，不是投資建議。

## 兩個模型怎麼切換

| 模式 | 行為 |
|------|------|
| **自動切換（預設）** | 趨勢環境 → 趨勢單；盤整環境 → 盤整單 |
| 只做趨勢 | 盤整時觀望 |
| 只做盤整 | 只做通道多空雙吃 |

- 圖上 **趨多 / 趨空** = 趨勢模型  
- 圖上 **盤多 / 盤空** = 盤整模型  
- 橘色通道 = 盤整上下軌（布林 ∩ 唐奇安）

## 盤整模型專屬面板（預設左上，可改位置）

環境過濾（至少 2/4 + 通道寬度合格才啟用）：

1. ADX ≤ 22  
2. CHOP ≥ 55  
3. 均線糾結  
4. 效率比偏低  
5. 通道寬度 1.2～6 ATR  
6. 時段 / 波動正常  

做多條件（分數 ≥ 4/7）：觸下軌、RSI 超賣、影線拒絕、Stoch、收盤回通道…  
做空條件：對稱（觸上軌 + RSI 超買）。

停損在軌道外側；TP1 中軌、TP2 對側軌道。

## 趨勢模型（預設右上面板，可改位置）

EMA 趨勢 + 回檔 + 高週期 H4/日線共振 + MACD + 斜率；盤整環境不開趨勢單。

## 用法

1. 貼上 `gold_mmm_entry_detector.pine`  
2. XAUUSD，建議 **H1**  
3. 左看盤整面板 ✓/✗，右看趨勢面板（設定 → ⑥顯示 → 可改「面板位置」）  
4. 警示可分開訂：盤整做多 / 盤整做空 / 趨勢做多 / 趨勢做空  

單筆風險建議 ≤ 1%。重大數據前後空手。
