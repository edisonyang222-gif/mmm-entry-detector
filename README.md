# 黃金 MMM 進場偵測器（小週期共振版）

把黃金進場條件收成可執行規則：**本週期回檔 + 高週期共振 + ADX + MACD + 斜率 + 時段**。  
介面、標籤、警示皆為**中文**。

> 沒有指標能保證賺錢。以下為歷史回測，不是未來獲利保證。

## 小週期怎麼變穩？

雜訊多時，單看 H1/M15 容易假訊號。新增較穩定的共振因素：

| 共振因素 | 作用 |
|----------|------|
| **高週期1 / 高週期2** | H1 必須與 H4、日線同向；避免逆大勢 |
| **ADX ≥ 18** | 過濾無趨勢盤整 |
| **MACD 柱同向且增強** | 確認動能，不只均線排列 |
| **EMA 斜率** | 趨勢還在走，不是走平 |
| **時段過濾（台北時間）** | 亞盤 07:00–14:00；倫敦 15:00–23:30；美盤 21:30–隔日 04:00。預設做倫敦+美盤 |
| **共振分數 ≥ 5/8** | 條件湊不夠就不進場 |

硬性條件（一定要過）：本週期趨勢、回檔 EMA、陽/陰線確認、高週期同向、時段、斜率。  
其餘進分數，達門檻才出訊號。

## 建議設定

| 圖表週期 | 第一共振 | 第二共振 | 時段過濾 | 備註 |
|----------|----------|----------|----------|------|
| **H1（推薦小週期）** | 240（H4） | D（日線） | 開 | 預設即為此 |
| M15 | 60（H1） | 240（H4） | 開（可改「只做重疊」） | 手動改參數 |
| H4 / D1 | 可關共振 | — | 可關 | 大週期本來就穩 |

風控預設：停損 **2 ATR**，TP1 **3 ATR**（平半倉），TP2 **5 ATR**。單筆風險 ≤ 1%。

## TradingView 用法

1. 貼上 `gold_mmm_entry_detector.pine` → 加入圖表  
2. 商品 **XAUUSD**，週期 **60（H1）**  
3. 右上角儀表板看：本週期 / 高週期1 / 高週期2 / ADX / MACD / 分數 / 狀態  
4. 出現「做多」「做空」與停損目標標籤再下單  
5. 警示選「黃金MMM做多 / 做空」

M15 請把「第一共振週期」改 `60`、「第二共振週期」改 `240`。

## Python 回測

```bash
pip install -r requirements.txt

# H1 + H4/日線共振（建議）
python3 backtest/gold_mmm_backtest.py --symbol GC=F --interval 1h --period 2y --htf1 4h --htf2 1D --min-score 5

# 只做多
python3 backtest/gold_mmm_backtest.py --symbol GC=F --interval 1h --period 2y --long-only

# 關閉共振對照
python3 backtest/gold_mmm_backtest.py --symbol GC=F --interval 1h --period 2y --no-mtf --no-adx --no-macd --min-score 3
```

## 實盤檢查清單

- [ ] 高週期1、高週期2 與訊號同向（儀表板都是「多」才做多）  
- [ ] ADX 達標、時段顯示「可做」  
- [ ] 共振分數 ≥ 門檻  
- [ ] 按標籤設停損/目標，單筆風險 ≤ 1%  
- [ ] 非農 / FOMC / CPI 前後空手
