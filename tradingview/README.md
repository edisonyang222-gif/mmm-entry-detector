# TradingView 安裝

1. 開啟任意圖表 → 下方 **Pine Editor**
2. 新建腳本，貼上 `MMXM_Entry_Detector.pine` 全部內容（`//@version=6`）
3. Save → **Add to chart**

## 畫面怎麼看（精簡）

預設**圖上幾乎不畫線**，避免整圖亂掉：

- 進場三角（E多 / E空）
- **右上固定表**：流動性路徑、DOL、E / R / T1 / T2 / RR、HTF、階段

盈虧數字請看右上表，不要再滿圖拉橫線。

可選（預設關）：
- 進場區短色帶
- 等待回踩黃底

## ERL ↔ IRL

右上「流動性」列會顯示：
- `ERL→IRL 偏多/偏空`
- `IRL→ERL 偏多/偏空`

## PO3（Power of Three / AMD）

右上「PO3」列會顯示當前階段：
1. **累積 ACC** — 區間盤整
2. **操控 MAN** — Judas 掃流動性（↓偏多 / ↑偏空）
3. **派發 DIST** — 真方向擴張（進場偏這段）

進場模型可選 **PO3派發進場**（自動要求派發同向）。也可只開啟判別、不強制過濾。

## 重要設定

- **ERT交易系統** / **MMXM第四階段**
- HTF→LTF 偏向過濾
- 進場確認：觸價 / 收K確認 / 收K進入失衡區

這是**指標**，不會自動下單。
