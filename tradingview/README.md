# TradingView 安裝

1. 開啟任意圖表 → 下方 **Pine Editor**
2. 新建腳本，貼上 `MMXM_Entry_Detector.pine` 全部內容（`//@version=6`）
3. Save → **Add to chart**

設定面板、右上狀態表、圖上標籤皆為**繁體中文**。

## 重要設定（先看這裡）

### ICT進場模型
- **進場模型**：MMXM第四階段（累積→掃蕩→擴張→回踩）
- **進場參考價**
  - 中點CE：失衡區 50%
  - 近端：先碰到的邊界
  - OTE62：位移腿 62% 回撤（落在 FVG 內才用）
- **進場確認方式**
  - **觸價可進場**：影線碰到即可（偏限價、較早）
  - **收K確認進場**：碰到後收盤回到進場側（預設、較穩）
  - **收K進入失衡區**：收盤落入 FVG 內才算

### 盈虧設定
- **停利計算方式**
  - 固定報酬比：用「目標報酬比 1:X」
  - 結構投射：依掃蕩深度投射
  - 兩者取遠：預設，目標較遠、報酬比較好看
- **目標報酬比**：預設 1:2
- **最小可接受報酬比**：低於此值不畫訊號
- 可另標 **1R** 參考線

## 圖上會看到什麼

- 黃框：等待回踩（尚未進場）
- 訊號出現後：紅色風險方塊、綠色獲利方塊、進場/停損/停利線
- 右上狀態表：目前階段、確認方式、報酬比

這是**指標**，不會自動下單。
