# TradingView 安裝

1. 開啟任意圖表 → 下方 **Pine Editor**
2. 新建腳本，貼上 `MMXM_Entry_Detector.pine` 全部內容（`//@version=6`）
3. Save → **Add to chart**

設定面板、右上狀態表、圖上標籤皆為**繁體中文**。

## 重要設定（先看這裡）

### ICT進場模型
- **進場模型**
  - **ERT交易系統**（預設）：HTF 偏向過濾 + LTF MMXM 第四階段，並標示 E / R / T1 / T2
  - **MMXM第四階段**：僅本週期結構（累積→掃蕩→擴張→回踩）
- **進場參考價**
  - 中點CE：失衡區 50%
  - 近端：先碰到的邊界
  - OTE62：位移腿 62% 回撤（落在 FVG 內才用）
- **進場確認方式**
  - **觸價可進場**：影線碰到即可（偏限價、較早）
  - **收K確認進場**：碰到後收盤回到進場側（預設、較穩）
  - **收K進入失衡區**：收盤落入 FVG 內才算

### HTF→LTF 多週期
- **啟用高週期(HTF)偏向過濾**：LTF 訊號必須與 HTF 方向一致
- **高週期時間框**：例如圖表用 5/15 分，HTF 用 `60` 或 `240`
- **HTF偏向判定**
  - 結構突破BOS（預設）
  - 收盤相對中軸
  - EMA方向
- 等待回踩時若 HTF 尚未同向，狀態表會顯示「等HTF」，不會強制進場

### ERT 交易系統（Entry / Risk / Target）
- **E**：進場價（FVG/CE/OTE）
- **R**：風險停損（掃蕩極端外 + ATR 緩衝）
- **T1**：部分目標（預設 1R）
- **T2**：最終停利（固定報酬比 / 結構投射 / 兩者取遠）
- ERT 模式預設強制要求 HTF 同向

### 盈虧設定
- **停利計算方式**
  - 固定報酬比：用「目標報酬比 1:X」當 T2
  - 結構投射：依掃蕩深度投射
  - 兩者取遠：預設，目標較遠、報酬比較好看
- **目標報酬比**：預設 1:2（= T2）
- **最小可接受報酬比**：低於此值不畫訊號

## 圖上會看到什麼

- 黃框：等待回踩（尚未進場；可帶 HTF 狀態）
- 訊號出現後：紅色風險方塊（R）、綠色獲利方塊（T）、E/R/T1/T2 標線
- 右上狀態表：模型、HTF 偏向、階段、ERT 清單、報酬比

建議用法：LTF 圖表執行進場，HTF 設為上一檔或兩檔週期（例如 15m + HTF 60）。

這是**指標**，不會自動下單。
