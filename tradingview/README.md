# TradingView 安裝

1. 開啟任意圖表 → 下方 **Pine Editor**
2. 新建腳本，貼上 `MMXM_Entry_Detector.pine` 全部內容（`//@version=6`）
3. Save → **Add to chart**

## 畫面怎麼看（精簡）

預設**圖上幾乎不畫線**，避免整圖亂掉：

- 進場三角（ALG多 / ALG空 等）
- **右上固定表**：①時間 / ②流動性 / ③位移 / ④目標、E / R / T1 / T2 / RR

盈虧數字請看右上表。

## 四大演算法模組（各自勾選）

設定裡 **「四大演算法模組」** 有四個獨立勾選：

| 勾選 | 規則 |
|------|------|
| **①時間演算法** | Asia 區間 → Judas 假突破 → 倫敦/紐約延續，才允許該方向進場 |
| **②流動性演算法** | 多需先掃 SSL、空需先掃 BSL（可要求收回收復） |
| **③位移演算法** | CISD 或 MSS + 位移腿 FVG 才算有效結構 |
| **④目標演算法** | 停利優先：下一未掃流動性 → EQH/EQL → IPDA 對側 |

關掉某個勾選 = 該規則不參與過濾／改寫。可只開其中幾個做對照。

### ①時間演算法
- 預設 Asia：紐約 20:00–00:00
- Judas 視窗：02–05（可調）
- 延續：倫敦 02–05 / 紐約 08–11 收過 Asia 中軸

### ②流動性演算法（BSL/SSL）
- 樞紐高低形成流動性池
- 掃蕩有效期內才允許進場；進場後消耗該次狀態

### ③位移演算法
- 位移K +（CISD 或 MSS）
- 位移後 N 根內必須出現 FVG，否則結構作廢

### ④目標演算法
- 覆蓋 T2：未掃 BSL/SSL → EQH/EQL → IPDA 對側
- 可選「找不到目標就不進場」

## PO3 / HTF / ERL↔IRL

仍可獨立使用；與四大模組並存。

## 重要設定

- 進場模型：**ICT演算法**（建議）或 MMXM / ERT / PO3
- 進場確認：觸價 / 收K確認 / 收K進入失衡區

這是**指標**，不會自動下單。
