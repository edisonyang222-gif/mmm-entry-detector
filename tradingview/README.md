# TradingView 安裝

1. 開啟任意圖表 → 下方 **Pine Editor**
2. 新建腳本，貼上 `MMXM_Entry_Detector.pine` 全部內容（`//@version=6`）
3. Save → **Add to chart**
4. 需要推播時：右鍵圖表 → Add alert → 選 `MMBM Entry` / `MMSM Entry`

設定面板、右上狀態表、圖上標籤皆為**繁體中文**。

## 圖上會看到什麼

- 黃框 **等待作多/作空**：已形成失衡區，等待回踩（尚未進場）
- 訊號當下才出現：紅色 **風險** / 綠色 **獲利** 方塊、進場/停損/停利線
- 藍框 **失衡區**、紫框 **累積**
- 右上角狀態表（中文）

## 偵測邏輯（較嚴謹）

1. 累積區間先站穩（預設至少 5 根）
2. 掃蕩流動性
3. 強勢位移 + 收破區間 + 留下失衡區（FVG）
4. **等價格回踩失衡區才出進場訊號**

## 時區

只依 K 線 OHLC，不綁 session／時區。

這是**指標**，不會自動下單。
